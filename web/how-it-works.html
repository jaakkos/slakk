The planner does not find the safest or most skiable line. It finds the lowest-cost path on a bare-ground grid under hard masks and soft penalties you set in the side panel. Treat every result as an unverified draft.

In the UI, controls are tagged Hard (never crossed), Soft (preferred by cost among legal lines), or Setup (grid / input only). The map key and layer control show the same hazards the search uses. After a plan, “Shaped by these settings” lists what produced the drawn line; if you change a control, the stale banner asks you to Plan again.

1. Build a searchable grid

Around your start → vias → end (or a recorded GPX corridor), the browser downloads Kartverket elevations and NVE steep/runout markings, then builds a raster at your chosen resolution (metres per cell). Optional hierarchical mode first searches at ~10 m, then refines inside a narrowed corridor at the fine resolution.

2. Hard constraints (never crossed)

Cells are blocked before search. A* cannot enter them:

  • Outside the corridor — farther than Corridor m from the straight/GPX reference line.
  • Steep terrain — DEM hillside slope above Ground slope max ° (default 35). This is the hillside angle, not the Skin track max °. Optional NVE steep colour bands (27–30° … ≥45°) can each be Block, Prefer around, or Off (default Off so your angle limits decide).
  • Avalanche runout (blue) — each NVE class (Short / Medium / Long) can be Block (Hard), Prefer around (Soft cost), or Off. Mix freely (e.g. Block Long, Prefer around Short). Cushion applies around Block / Prefer-around zones.
  • Invalid elevation — missing DEM, dilated by one cell so routes cannot clip corners.
  • Kick-turn hard ceiling (when Kick-turn max ° > 0) — raw along-edge grades above that kick-turn limit, and extreme raw slopes.

Each allowed step is also profile-checked along the edge so sustained climbing respects Skin track max °, brief steeper bits stay under Kick-turn max ° (if enabled), and height loss on the ascent cannot exceed Allowed drop max °.

3. Soft cost (what “best” means)

Among paths that survive the masks, A* minimises a weighted length. Moving from one cell to a neighbour costs roughly: 

length × (1
  + steepness penalty on climbs
  + descent_cost × downhill grade
  + distance from the corridor / corridor width
  + NVE runout class weight (if penalize)
  + ridge / gully terms (if Ridges on)
  + kick-turn overage term (if Kick-turn max ° > 0)
  + diversity penalty (alternatives only))
  • Preserve ascent (avoid ups and downs) — this tool plans a climb, not a descent line. Any step that loses height is charged Drop penalty × (metres lost) (default 10), so dropping into a valley and climbing out is expensive compared with a longer traverse that keeps height. Allowed drop max ° is a hard cap: steeper height-loss steps are blocked entirely. Together these push the search toward a continuous climb.
  • Steepness — climbs steeper than about 12% grade get a quadratic extra, so gentle grades beat short brutal rises when both are legal.
  • Corridor pull — cells farther from the reference line cost more, so the route stays near your sketched/GPX corridor unless a detour is worth it.
  • Runout Prefer around — NVE short / medium / long blues set to Prefer around add a built-in Soft weight per metre (4 / 12 / 24, favouring short over long). Block is Hard instead. Off adds nothing. Planning weights, not avalanche risk scores.
  • Ridges — ridges (locally high) are slightly preferred; gullies (locally low) are heavily charged, so the search tends to stay out of drainage lines when a ridge or open slope exists.
  • Bump cost — local DEM roughness (elevation stddev in ~15 m). Bumpy / broken ground costs extra so the line prefers smoother slopes that are easier to climb with skins. Soft only; 0 turns it off. This is not a rock or vegetation layer — only what the bare DEM resolves.
  • Kick-turn max — grades between Skin track max ° and Kick-turn max ° are allowed on the raw DEM but charged extra, so brief kick-turns / walls can appear without letting the whole climb stay that steep. 0 turns kick-turns off.

Optional turn cost (CLI; web defaults keep it modest) charges heading changes so micro-zigzags are replaced by longer traverses when that is cheaper.

4. How A* searches

  1. Each cell can step to 16 neighbours (cardinal, diagonal, and knight-like offsets) so headings are not locked to 45°.
  2. Edge costs are precomputed for every allowed step.
  3. A* expands cells in order of cost so far + straight-line estimate to the goal (an admissible heuristic), so the first complete path it accepts is optimal for that cost model.
  4. With vias, it solves leg by leg (start→via₁→…→end). With Lock start m on a GPX, the start of the recorded track is preserved and search begins after that distance.
  5. After search, collinear points are dropped and the dense line is validated again at ~1 m spacing. Failures here reject the candidate rather than silently loosening limits.

5. Alternatives

If Alt. routes > 1, the planner runs again with an extra cost band (~50 m) around earlier lines so later searches find a different corridor. Every alternative still obeys the same hard masks. Compare metrics (distance, runout metres, pitch), not raw search cost — diversity cost is baked into alternative scores.

6. Display / GPX smoothing

On steep ground the search often uses short zigzags so each grid step stays under Skin track max °. That is correct for the model, but annoying on a GPS. Smooth GPX m (default 8) runs Ramer–Douglas–Peucker on the finished path for the map line and the downloaded GPX only. Set it to 0 for the raw search geometry. Metrics stay on the raw candidate; smoothed chords are not re-checked against Hard climb limits.

7. Share links

Copy share link puts a URL in the clipboard whose hash carries your current settings and waypoints. When a candidate exists, the selected line is included too (smoothed for size). If planning failed, the link is still available as setup-only (settings + points, plus a short note of the last error) so someone else can open the same problem and Plan again. Opening a link with geometry draws it immediately without re-running A*; setup-only links restore controls and points only. Re-planning may differ if Kartverket/NVE data or the model change. Uploaded GPX corridors are not embedded (too large); re-plan uses the shared waypoints as a point-to-point corridor unless the recipient uploads a GPX again. Shared candidates remain unverified drafts.

8. What this never models

  • Snow depth, slab, forecast, cornices, ice, or bootpacking vs skinning
  • Vegetation, streams narrower than ~two cells, cliffs as geometry, or land access
  • Whether a kick turn or pitch is practical for you
  • Descent lines — ascent candidates only

Absence of an NVE marking is not clearance. Always check Varsom, maps, and the terrain itself.
