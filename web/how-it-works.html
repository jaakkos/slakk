The planner does not find the safest or most skiable line. It finds the lowest-cost path on a bare-ground grid under hard masks and soft penalties you set in the side panel. Treat every result as an unverified draft.

In the UI, controls are tagged Hard (never crossed), Soft (preferred by cost among legal lines), or Setup (grid / input only). The map key and layer control show the same hazards the search uses. After a plan, “Shaped by these settings” lists what produced the drawn line; if you change a control, the stale banner asks you to Plan again.

1. Build a searchable grid

Around your start → vias → end (or a recorded GPX corridor), the browser downloads Kartverket elevations and NVE steep/runout markings, then builds a raster at your chosen resolution (metres per cell). Optional hierarchical mode first searches at ~10 m, then refines inside a narrowed corridor at the fine resolution.

2. Hard constraints (never crossed)

Cells are blocked before search. A* cannot enter them:

  • Outside the corridor — farther than Corridor m from the straight/GPX reference line.
  • Steep terrain — DEM slope above the terrain limit, plus NVE “steep” pixels (and their buffer).
  • Runout (avoid mode) — NVE avalanche runout pixels (and buffer). In penalize mode these stay open but expensive.
  • Invalid elevation — missing DEM, dilated by one cell so routes cannot clip corners.
  • Pitch hard ceiling (when Pitch ° > 0) — raw along-edge grades above the pitch limit, and extreme raw slopes.

Each allowed step is also profile-checked along the edge so the climb/descent cannot exceed Max uphill ° (and downhill limit) on the elevations used for grades.

3. Soft cost (what “best” means)

Among paths that survive the masks, A* minimises a weighted length. Moving from one cell to a neighbour costs roughly: 

length × (1
  + steepness penalty on climbs
  + descent_cost × downhill grade
  + distance from the corridor / corridor width
  + NVE runout class weight (if penalize)
  + ridge / gully terms (if Landforms on)
  + pitch-overage term (if Pitch ° > 0)
  + diversity penalty (alternatives only))
  • Preserve ascent (avoid ups and downs) — any downhill step is charged Descent cost × (metres lost) (default Descent cost = 10), so losing elevation is expensive compared with a longer traverse that keeps height. Max downhill ° is a hard cap: steeper descents are blocked entirely. Together these push the search toward a continuous climb instead of dipping into a valley and climbing back out.
  • Steepness — climbs steeper than about 12% grade get a quadratic extra, so gentle grades beat short brutal rises when both are legal.
  • Corridor pull — cells farther from the reference line cost more, so the route stays near your sketched/GPX corridor unless a detour is worth it.
  • Runout penalize — NVE short / medium / long blues add increasing per-metre weights (defaults favour short runout over long). These are planning weights, not avalanche risk scores.
  • Landforms — ridges (locally high) are slightly preferred; gullies (locally low) are heavily charged, so the search tends to stay out of drainage lines when a ridge or open slope exists.
  • Micro-terrain — local DEM roughness (elevation stddev in ~15 m). Bumpy / broken ground costs extra so the line prefers smoother slopes that are easier to climb with skins. Soft only; 0 turns it off. This is not a rock or vegetation layer — only what the bare DEM resolves.
  • Pitch — grades between Max uphill ° and Pitch ° are allowed on raw DEM but charged extra, encouraging short steep pitches rather than long ones.

Optional turn cost (CLI; web defaults keep it modest) charges heading changes so micro-zigzags are replaced by longer traverses when that is cheaper.

4. How A* searches

  1. Each cell can step to 16 neighbours (cardinal, diagonal, and knight-like offsets) so headings are not locked to 45°.
  2. Edge costs are precomputed for every allowed step.
  3. A* expands cells in order of cost so far + straight-line estimate to the goal (an admissible heuristic), so the first complete path it accepts is optimal for that cost model.
  4. With vias, it solves leg by leg (start→via₁→…→end). With Keep first m on a GPX, the start of the recorded track is preserved and search begins after that distance.
  5. After search, collinear points are dropped and the dense line is validated again at ~1 m spacing. Failures here reject the candidate rather than silently loosening limits.

5. Alternatives

If Alternatives > 1, the planner runs again with an extra cost band (~50 m) around earlier lines so later searches find a different corridor. Every alternative still obeys the same hard masks. Compare metrics (distance, runout metres, pitch), not raw search cost — diversity cost is baked into alternative scores.

6. Display / GPX smoothing

On steep ground the search often uses short zigzags so each grid step stays under Max uphill °. That is correct for the model, but annoying on a GPS. Smooth export m (default 8) runs Ramer–Douglas–Peucker on the finished path for the map line and the downloaded GPX only. Set it to 0 for the raw search geometry. Metrics stay on the raw candidate; smoothed chords are not re-checked against Hard climb limits.

7. Share links

Copy share link puts a URL in the clipboard whose hash carries your current settings, waypoints, and the selected candidate line (smoothed for size). Opening the link restores those controls and draws that geometry immediately — it does not re-download DEM or re-run A* until you click Plan. Re-planning may differ slightly if Kartverket/NVE data or the model change. Uploaded GPX corridors are not embedded (too large); re-plan uses the shared waypoints as a point-to-point corridor unless the recipient uploads a GPX again. Shared candidates remain unverified drafts.

8. What this never models

  • Snow depth, slab, forecast, cornices, ice, or bootpacking vs skinning
  • Vegetation, streams narrower than ~two cells, cliffs as geometry, or land access
  • Whether a kick turn or pitch is practical for you
  • Descent lines — ascent candidates only

Absence of an NVE marking is not clearance. Always check Varsom, maps, and the terrain itself.
